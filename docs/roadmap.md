# Current limits

The application has not been validated on every Windows 10/11 build, DPI setting, audio driver, or multi-monitor arrangement. MSAA support needs testing with screen-reader users.

Voice recognition, notification access, a built-in language model, microphone recording, amplification, and equalization are not implemented. The existing voice animation is a preview. The Bluetooth page delegates profile-specific connection management and LE devices to Windows.

Future changes should preserve low idle resource use and native Windows audio control.
