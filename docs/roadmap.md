# Current limits

The application has not been validated on every Windows 10/11 build, DPI setting, audio driver, or multi-monitor arrangement. MSAA support needs testing with screen-reader users. Exclusive-mode audio and driver-specific paths can bypass system effects.

Voice recognition, notification access, a built-in language model, microphone recording, and a Hext limiter are not implemented. The existing voice animation is a preview. The Bluetooth page delegates profile-specific connection management and LE devices to Windows.

Future changes should preserve low idle resource use and the optional nature of audio processing. A new add-on should declare its source, license, pinned release, installation behavior, and removal route before being offered in the interface.
